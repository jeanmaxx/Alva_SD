# ALVA Soluciones Digitales

Plataforma corporativa y administrativa de **ALVA Soluciones Digitales**.

## Objetivo

Este repositorio será el núcleo web de ALVA: sitio público, catálogo de soluciones y zona administrativa para gestionar clientes, productos, licencias, suscripciones, cobranza y soporte.

## Productos iniciales

- **TTD** — producto activo.
- **CRM** — producto activo.
- **Producto 03** — reservado para la siguiente plataforma.

## Arquitectura prevista

- `alvasd.com` → sitio corporativo.
- `admin.alvasd.com` → administración ALVA.
- `ttd.alvasd.com` → TTD.
- `crm.alvasd.com` → CRM.
- futuros productos → subdominios independientes.
